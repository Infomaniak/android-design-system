## Icons

Icons are exposed as `Symbol`s through `EsdsIcons` (e.g. `EsdsIcons.Plus`). A `Symbol` groups every size of an icon
(`ExtraSmall` to `ExtraLarge`); `Symbol.current` resolves the size provided by `LocalEsdsIconSize` (`Medium` by default).

The sized `ImageVector`s in `Icons/…/imagevector/<size>/` and the `Symbol`s in `Icons/…/symbols/` are auto-generated by the
Android icons build of the Infomaniak design-system repository and must not be edited manually. The `Symbol` interface itself
lives in `Icons/…/symbols/_Symbol.kt`.
